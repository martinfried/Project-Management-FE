# Project Management Frontend

Modern single-page application built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS**, and **shadcn/ui**.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Data Table**: [TanStack Table v8](https://tanstack.com/table)
- **API Client**: [openapi-fetch](https://openapi-ts.dev/openapi-fetch/) typed with OpenAPI schema
- **Icons**: [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```

### Docker

```bash
docker build -t project-management-frontend .
docker run -p 3000:80 project-management-frontend
```
